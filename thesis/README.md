# Master's thesis — LaTeX source (bilingual)

Two parallel versions of the same thesis, kept in lockstep:

- `en/` — English (`en/main.tex`)
- `es/` — Spanish (`es/main.tex`)
- `common/` — shared across both: `preamble.tex`, `references.bib`, `figures/`
- `figures_src/` — Python script that regenerates every figure

## Structure

Each language directory has `main.tex` plus `frontmatter/` and `chapters/`. The
chapters map one-to-one onto the demand-driven pipeline (workstreams W1–W8):

| Chapter | Content |
|---------|---------|
| 1 Introduction | Motivation, the circularity problem, research questions RQ1–RQ4 |
| 2 Theoretical framework | Node–Place model, demand modeling, MCDA, ML siting |
| 3 Study area & data | ZMG, the AGEB, data sources |
| 4 **Methodology** | The eight workstreams (fully drafted — template chapter) |
| 5 Results | ZMG findings per workstream |
| 6 Transferability | Toluca + Aguascalientes |
| 7 Discussion | Diagnostic vs generative contribution, limitations |
| 8 Conclusions | Answers to RQ1–RQ4, future work |

Chapter 4 (Methodology) is fully written in both languages as the quality template;
the remaining chapters are structured skeletons with section outlines and `[TODO]`
markers.

## Building

The project builds with **[Tectonic](https://tectonic-typesetting.github.io/)**, a
single-binary LaTeX engine that auto-downloads packages (no multi-GB TeX Live
install). It also builds unchanged on **Overleaf** (upload the `thesis/` folder;
set the main document to `en/main.tex` or `es/main.tex`; Overleaf will use its own
`biber`/`bibtex`).

```bash
# one-time: install tectonic (see its site) — or use Overleaf
make figures      # regenerate figures from the live DB + outputs/ CSVs
make en           # -> en/main.pdf
make es           # -> es/main.pdf
make all          # figures + both PDFs
```

To view the PDF locally: open `en/main.pdf` / `es/main.pdf` in any PDF viewer, or
use VS Code with the *LaTeX Workshop* extension for an in-editor preview.

## Figures

All figures are generated by `figures_src/make_thesis_figures.py` into
`common/figures/*.pdf` (vector). Maps come from the live `gdl_metro` database
(needs the pipeline DB up); charts come from committed `outputs/` CSVs. Re-run
`make figures` after any pipeline re-run to refresh them.

## Citations

References live in `common/references.bib`. The preamble uses `biblatex` with the
`bibtex` backend (so it compiles under Tectonic); switch to `backend=biber` in
`common/preamble.tex` for richer author-year/APA styles on Overleaf. Several
entries are placeholders (`note = {Placeholder ...}`) to be completed with final
citation details.
